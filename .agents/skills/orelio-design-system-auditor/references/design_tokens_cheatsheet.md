# Orelio Design Tokens Cheatsheet

| Category | Tailwind / Hex Token | Description |
| :--- | :--- | :--- |
| **Primary Navy** | `#00162A` | Top headings, primary values |
| **Teal Green** | `#006A65` | Hover borders, progress bars, active text |
| **Forest Green** | `#004D40` | Stats card container background |
| **Body Gray** | `#43474D` | Section titles, standard text |
| **Muted Subtext** | `#74777F` | Subtitles, account numbers, uppercase field headers |
| **Light Neutral Fill** | `#F2F4F5` | Matured card background, badge fill |
| **Border Neutral** | `#C3C6CE` / 30% | Card borders (`border-[#C3C6CE]/30`) |
| **Matured Border** | `#BFC9C4` / 10% | Matured card border (`border-[#BFC9C4]/10`) |
| **Destructive Red** | `#BA1A1A` | Delete popover menu text |
